Guides take one task from start to finish, in your app: which protection to choose, where each piece of code goes, what the user sees, and what to do when a step fails.

If you are new to the package, read the [Quick start](../start/quick-start) and [Protection](../fundamentals/protection) first: the guides build on `keychain`, `createKeychain` and the options of an item.
