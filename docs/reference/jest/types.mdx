`@apexnative/keychain/jest` also exports every type of the package, the same as `@apexnative/keychain` does; they are on the pages of their sections. These are the types of the mock's own controls, [`keychainMock`](/api/jest/keychainMock).

## KeychainMock {#keychainmock}

The type of `keychainMock`.

```ts
type KeychainMock = {
  reset(): void;
  setDevice(device: Partial<MockDevice>): void;
  failNextAuthentication(code: KeychainErrorCode): void;
  changeBiometry(): void;
  prompts(): MockPrompt[];
  addMigrationSource(item: MockMigrationItem): void;
  migrationSources(): MockMigrationSource[];
};
```

  label="Method"

## MockDevice {#mockdevice}

The device the mock simulates. [`setDevice`](/api/jest/keychainMock#setDevice) takes any part of it.

```ts
type MockDevice = {
  defaultService: string;
  biometryTypes: BiometryType[];
  biometryEnrolled: boolean;
  passcodeSet: boolean;
  faceIDUsageDescription: boolean;
  androidApi: number | null;
  hardwareSecurityLevel: HardwareSecurityLevel | null;
};
```

<Params
  label="Field"
  items={[
    { name: 'defaultService', type: 'string', default: "'dev.apexnative.keychain.mock'", text: 'The service of the default store, `keychain`: the bundle identifier or the application id of a real app. A react-native-keychain generic password planted under it is the one `migrateFromReactNativeKeychain` moves by default.' },
    { name: 'biometryTypes', type: 'BiometryType[]', default: "['faceID']", text: 'The biometric hardware: what `getBiometryTypes` returns. `[]` is a device without a sensor, where the biometric access controls are `noHardware`.' },
    { name: 'biometryEnrolled', type: 'boolean', default: 'true', text: 'Whether biometry is enrolled. Without it `getBiometryState()` is `null`, and `biometryAny`, `biometryCurrentSet` and `biometryCurrentSetOrPasscode` are `notEnrolled`.' },
    { name: 'passcodeSet', type: 'boolean', default: 'true', text: 'Whether the device has a passcode: what `isPasscodeSet` returns. Without it every access control is `passcodeNotSet`, and `whenPasscodeSetThisDeviceOnly` can\'t be written.' },
    { name: 'faceIDUsageDescription', type: 'boolean', default: 'true', text: 'iOS: whether the app has `NSFaceIDUsageDescription` in its Info.plist.     { name: 'androidApi', type: 'number | null', default: 'null', text: 'Android: the API level. `null` is a device that isn\'t an Android one. Below 30 the passcode variants are `unsupportedOS`, and a write with one, or with `authValidity` above 0, rejects with `UNSUPPORTED`.' },
    { name: 'hardwareSecurityLevel', type: 'HardwareSecurityLevel | null', default: 'null', text: 'Android: the best hardware a new key can live in, what `getHardwareSecurityLevel` returns. `null` is iOS, where `keyStorage` means nothing. With a level, `tee` stays in the TEE even with StrongBox, `strongbox` falls back to the TEE, and `strongboxRequired` rejects with `HARDWARE_UNAVAILABLE` unless the level is `strongbox`.' },
  ]}

## MockMigrationItem {#mockmigrationitem}

An item of an old library, as that library left it on the device: what [`addMigrationSource`](/api/jest/keychainMock#addMigrationSource) plants. One of three shapes, with three optional fields shared by all of them.

```ts
type MockMigrationItem = {
  requiresAuth?: boolean;
  corrupted?: boolean;
  accessGroup?: string;
} & (
  | {
      // A generic password of react-native-keychain.
      library: 'reactNativeKeychain';
      service: string;
      username: string;
      password: string;
    }
  | {
      // Internet credentials of react-native-keychain.
      library: 'reactNativeKeychain';
      server: string;
      username: string;
      password: string;
    }
  | {
      // An item of expo-secure-store.
      library: 'expoSecureStore';
      key: string;
      value: string;
      keychainService?: string;
    }
);
```

<Params
  label="Field"
  items={[
    { name: 'library', type: "'reactNativeKeychain' | 'expoSecureStore'", required: true, text: 'The library that wrote it.' },
    { name: 'service', type: 'string', text: 'react-native-keychain, a generic password: its service. It becomes the credentials of the store of that service.' },
    { name: 'server', type: 'string', text: 'react-native-keychain, internet credentials: the server. They become the credentials with that `server`.' },
    { name: 'username, password', type: 'string', text: 'react-native-keychain: the credentials.' },
    { name: 'key, value', type: 'string', text: 'expo-secure-store: the key and the value. The item keeps its key.' },
    { name: 'keychainService', type: 'string', default: "'app'", text: 'expo-secure-store: the `keychainService` the item was stored with.' },
    { name: 'requiresAuth', type: 'boolean', default: 'false', text: 'The old item is protected: `migrateFrom…` skips it as `requiresAuth`, and `migrateItem` reads it with a prompt.' },
    { name: 'corrupted', type: 'boolean', default: 'false', text: 'Reading it fails with `DATA_CORRUPTED`, as bytes that aren\'t text do.' },
    { name: 'accessGroup', type: 'string', text: 'iOS: the access group the old item is in. A migration that names an `accessGroup` finds only the items of that group.' },
  ]}
/>

## MockMigrationSource {#mockmigrationsource}

A planted item that is still there, as [`migrationSources()`](/api/jest/keychainMock#migrationSources) returns it.

```ts
type MockMigrationSource = {
  library: 'reactNativeKeychain' | 'expoSecureStore';
  kind: 'genericPassword' | 'internetPassword' | 'secureStore';
  service: string;
  account: string;
  requiresAuth: boolean;
  migrated: boolean;
};
```
