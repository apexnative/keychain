Internet credentials are a user name and a password for a server. Here they are the [credentials](/api/storage/methods#setCredentials) of the default store with that `server`: the item `credentials:<server>`, the user name its label. With an `accessGroup`, the store is that of the access group.

## Usage {#usage}

```ts title="src/api/credentials.ts"
import * as Keychain from '@apexnative/keychain/compat';

const SERVER = 'api.example.com';

export async function remember(username: string, password: string) {
  await Keychain.setInternetCredentials(SERVER, username, password, {
    accessible: Keychain.ACCESSIBLE.AFTER_FIRST_UNLOCK_THIS_DEVICE_ONLY,
  });
}

export async function recall() {
  const credentials = await Keychain.getInternetCredentials(SERVER);
  return credentials ? { username: credentials.username, password: credentials.password } : null;
}

export async function forget() {
  await Keychain.resetInternetCredentials({ server: SERVER });
}
```

The same item through the core API:

```ts
import { keychain } from '@apexnative/keychain';

await keychain.getCredentials({ server: 'api.example.com' }); // { username, password } or null
```

Every function needs the server as a non-empty string: without one it rejects with `INVALID_ARGUMENT`.

## setInternetCredentials {#setInternetCredentials}

```ts
function setInternetCredentials(
  server: string,
  username: string,
  password: string,
  options?: SetOptions
): Promise<Result>;
```

<Facts returns="Promise<Result>" prompt="Never: a write shows no prompt, whatever its `accessControl`" throws="`INVALID_ARGUMENT`, `UNSUPPORTED`, `HARDWARE_UNAVAILABLE`, and what the device can't do: `BIOMETRY_NOT_ENROLLED`, `PASSCODE_NOT_SET`, …" />

Writes the user name and the password of the server, in place of what was there. It calls [`setCredentials`](/api/storage/methods#setCredentials) with `server`.

<Params
  items={[
    { name: 'server', type: 'string', required: true, text: 'The server, such as `api.example.com`. Any non-empty string without U+0000. It becomes part of the key `credentials:<server>`, at most 256 characters, so it is readable without a prompt.' },
    { name: 'username', type: 'string', required: true, text: 'Kept as the label of the item, outside the secret. Not empty, without U+0000.' },
    { name: 'password', type: 'string', required: true, text: 'The secret. Any string without U+0000.' },
    { name: 'options', type: 'SetOptions', text: 'How to protect the item: `accessible`, `accessControl`, `cloudSync`, `accessGroup`, `securityLevel`, as for [setGenericPassword](./generic-passwords#setGenericPassword). `service` is ignored.' },
  ]}
/>

```ts
await Keychain.setInternetCredentials('api.example.com', 'ivan', 'secret');
// { service: 'api.example.com', storage: 'keychain' }
```

It resolves with the server as `service`, and `storage`: `'keychain'` on iOS, `'KeystoreAESGCM'` on Android.

## getInternetCredentials {#getInternetCredentials}

```ts
function getInternetCredentials(
  server: string,
  options?: GetOptions
): Promise<InternetCredentials | false>;
```

<Facts returns="Promise<InternetCredentials | false>" prompt="When the item was written with an `accessControl`" throws="`INVALID_ARGUMENT` without a server; what the prompt ends with: `USER_CANCELED`, `LOCKOUT`, `KEY_INVALIDATED`, …" />

Reads the user name and the password of the server, or `false` when there are none. It calls [`getCredentials`](/api/storage/methods#getCredentials) with `server`.

<Params
  items={[
    { name: 'server', type: 'string', required: true, text: 'The server the credentials were written for.' },
    { name: 'options', type: 'GetOptions', text: 'The texts of the prompt (`authenticationPrompt`) and the `accessGroup`. See [GetOptions](./types#getoptions).' },
  ]}
/>

```ts
await Keychain.getInternetCredentials('api.example.com');
// { server: 'api.example.com', service: 'api.example.com', username: 'ivan', password: 'secret', storage: 'keychain' }
```

The prompt works as for [`getGenericPassword`](./generic-passwords#getGenericPassword): a string is the title, and without `authenticationPrompt` the texts are rnk's.

## hasInternetCredentials {#hasInternetCredentials}

```ts
function hasInternetCredentials(options: string | BaseOptions): Promise<boolean>;
```

<Facts returns="Promise<boolean>" prompt="Never" throws="`INVALID_ARGUMENT` without a server" />

Whether the server has credentials. It takes the server, or options with `server` (and `accessGroup`), and calls [`hasItem`](/api/storage/methods#hasItem) with the key `credentials:<server>`.

```ts
await Keychain.hasInternetCredentials('api.example.com'); // true
await Keychain.hasInternetCredentials({ server: 'api.example.com' }); // the same
```

## resetInternetCredentials {#resetInternetCredentials}

```ts
function resetInternetCredentials(options: string | BaseOptions): Promise<void>;
```

<Facts returns="Promise<void>" prompt="Never" throws="`INVALID_ARGUMENT` without a server" />

Deletes the credentials of the server. It takes the server, or options with `server`, and calls [`removeCredentials`](/api/storage/methods#removeCredentials) with it. It resolves `undefined`, also when there was nothing to delete.

```ts
await Keychain.resetInternetCredentials('api.example.com');
await Keychain.resetInternetCredentials({ server: 'api.example.com' }); // the same
```
