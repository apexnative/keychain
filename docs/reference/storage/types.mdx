## SetOptions {#setoptions}

```ts
type SetOptions = {
  accessible?: Accessible;
  accessControl?: AccessControl;
  authValidity?: number;
  synchronizable?: boolean;
  android?: AndroidOptions;
  label?: string;
};
```

The options of a write: [`setItem`](./methods#setItem), [`setBytes`](./methods#setBytes), [`setItemSync`](./methods#setItemSync), and, without `label`, [`setCredentials`](./methods#setCredentials). Each protection option overrides the storage's for this item; what isn't given comes from the storage, then from the defaults. The combination is checked as a whole: `{ authValidity: 30 }` on a storage of `biometryCurrentSet` throws `INVALID_ARGUMENT`.

The service and the access group aren't write options: they belong to the storage.

## GetOptions {#getoptions}

```ts
type GetOptions = {
  prompt?: Prompt;
};
```

The options of a read: [`getItem`](./methods#getItem), [`getBytes`](./methods#getBytes), [`getCredentials`](./methods#getCredentials).

<Params
  label="Field"
  items={[
    { name: 'prompt', type: 'Prompt', text: 'The texts of the prompt of this read, merged field by field over the storage\'s: `{ title }` keeps the storage\'s `cancel`. See [Prompt](/api/options/types#prompt).' },
  ]}
/>

A read uses the protection the item was written with; there is nothing else to choose.

## ItemInfo {#iteminfo}

```ts
type ItemInfo = {
  key: string;
  label?: string;
  accessible: Accessible;
  accessControl: AccessControl;
  synchronizable: boolean;
  createdAt: number;
  modifiedAt: number;
  android?: {
    securityLevel: HardwareSecurityLevel;
  };
};
```

What [`getItemInfo`](./methods#getItemInfo) reports about an item, without a prompt.

<Params
  label="Field"
  items={[

    { name: 'accessControl', type: 'AccessControl', required: true, text: 'What unlocks the item, as it was written.' },

## Credentials {#credentials}

```ts
type Credentials = {
  username: string;
  password: string;
};
```

A username and a password, written by [`setCredentials`](./methods#setCredentials) as one item and read back by [`getCredentials`](./methods#getCredentials).

<Params
  label="Field"
  items={[
    { name: 'username', type: 'string', required: true, text: 'Kept as the item\'s label, readable without a prompt. Can\'t be empty or contain U+0000.' },
    { name: 'password', type: 'string', required: true, text: 'Kept as the item\'s value. May be empty; can\'t contain U+0000.' },
  ]}
/>

## CredentialsOptions {#credentialsoptions}

```ts
type CredentialsOptions = {
  server?: string;
};
```

Which credentials: the app's own, or those of a server.
