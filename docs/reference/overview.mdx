## Entry points {#entry-points}

| Import from | What it has |
| --- | --- |
| `@apexnative/keychain` | The storage, its options, the device capabilities, the errors |
| [`@apexnative/keychain/migrate`](/api/migrate/migrateFromReactNativeKeychain) | Moving the items of react-native-keychain and expo-secure-store into the package |
| [`@apexnative/keychain/compat`](/api/compat/overview) | The functions of react-native-keychain over the package's storage |
| [`@apexnative/keychain/jest`](/api/jest/overview) | The same API over a storage in memory, and `keychainMock` to drive it in tests |
| [`app.plugin.js`](/api/plugin) | The Expo config plugin: `"plugins": ["@apexnative/keychain"]` |

`/migrate` and `/compat` are separate so that an app that doesn't use them doesn't load them.

## Rules of every call {#conventions}

- **Errors.** Every call fails with a `KeychainError`: an async method rejects, a sync method throws. A missing value is `null`, never an error. A method without a value resolves to `undefined`.
- **Checks first.** Keys, values and options are checked in JavaScript before the native call, the same way on iOS and Android. A key that breaks the rules, a string with U+0000, an option with a wrong value, or an option name that doesn't exist throws `INVALID_ARGUMENT`.
- **Prompts.** Only reads of a protected item (`getItem`, `getBytes`, `getCredentials`, and `migrateItem` of a protected old item) can show the system prompt. Writes, removals, `hasItem`, `getItemInfo`, `getAllKeys`, `clear`, the sync methods and the device functions never do.
- **Never weaker.** An option means the same on both platforms. A device that can't give an item its protection fails the write; the item is never stored with less.
- **Only its own items.** The package reads, lists and removes only the items it wrote; those of other libraries are moved by `/migrate`.
- **Platforms.** Every export works on iOS and Android. On the web every call throws `UNSUPPORTED`; so does a call in an app without the native module (Expo Go, or an app not rebuilt after the install), with a message that says how to fix it. Importing the package never fails.
