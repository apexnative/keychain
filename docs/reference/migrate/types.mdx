## MigrationReport {#migrationreport}

```ts
type MigrationReport = {
  migrated: string[];
  skipped: SkippedItem[];
  warnings: Array<{ key: string; kind: MigrationKind; error: KeychainError }>;

```

## SkipReason {#skipreason}

```ts
type SkipReason = 'requiresAuth' | 'notFound' | 'exists' | 'error';
```

| Reason | Means |
| --- | --- |
| `'requiresAuth'` | The old item is protected, and `migrateFrom…` never shows a prompt. [`migrateItem`](./migrateItem) moves it |
| `'notFound'` | The old item is gone, or has no value |
| `'exists'` | The key is taken in this package, and nothing is overwritten; or an earlier run moved the item and kept it |
| `'error'` | Reading or writing failed; `error` says how |

## MigrationKind {#migrationkind}

```ts
type MigrationKind = 'genericPassword' | 'internetPassword' | 'secureStore';
```

| Kind | The old item | Becomes |
| --- | --- | --- |
| `'genericPassword'` | A generic password of react-native-keychain | The credentials of the storage whose service is the password's |
| `'internetPassword'` | Internet credentials of react-native-keychain | The credentials of `into` with `server` |
| `'secureStore'` | An item of expo-secure-store | The item with the same key in `into` |

## MigrationItem {#migrationitem}

```ts
type MigrationItem =
  | { library: 'reactNativeKeychain'; service?: string; server?: undefined }
  | { library: 'reactNativeKeychain'; server: string; service?: undefined }
  | { library: 'expoSecureStore'; key: string; keychainService?: string };
```

One old item, for [`migrateItem`](./migrateItem).

| Item | Names |
| --- | --- |
| `{ library: 'reactNativeKeychain' }` | The generic password of rnk's default service |
| `{ library: 'reactNativeKeychain', service: 'auth' }` | The generic password of the service `auth` |
| `{ library: 'reactNativeKeychain', server: 'api.example.com' }` | The internet credentials of the server |
| `{ library: 'expoSecureStore', key: 'token' }` | The item `token` of expo-secure-store's default service: `app` on iOS, `key_v1` on Android |
| `{ library: 'expoSecureStore', key: 'token', keychainService: 'auth' }` | The item `token` of the `keychainService` `auth` |

Both `service` and `server` at once is `INVALID_ARGUMENT`.
