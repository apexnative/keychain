`migrateFromReactNativeKeychain` and `migrateFromExpoSecureStore` never show a prompt, so they leave a protected item where it is and report it as `requiresAuth`. `migrateItem` moves one such item: it shows the prompt of the old item, writes the value into this package with the protection you give, and finishes the old item.

## Usage {#usage}

```ts title="src/auth/unlock.ts"
import { AccessControl, Accessible } from '@apexnative/keychain';
import { migrateItem } from '@apexnative/keychain/migrate';

// On the screen that used to unlock rnk's protected password with Face ID.
const report = await migrateItem(
  { library: 'reactNativeKeychain', service: 'auth' },
  {
    prompt: { title: 'Unlock your account' },
    setOptions: {
      accessible: Accessible.WhenUnlockedThisDeviceOnly,
      accessControl: AccessControl.BiometryCurrentSet,
    },
    removeSource: true,
  }
);

if (report.migrated.length === 1) {
  // The password is now the credentials of createKeychain({ service: 'auth' }).
}
```

### Returns {#returns}

A [MigrationReport](./types#migrationreport) of the one item: its key in `migrated`, or in `skipped` with a reason.

## Outcomes {#outcomes}

| What happened | The report |
| --- | --- |
| Moved | `migrated: [key]` |
| The user canceled the prompt | `skipped: [{ key, kind, reason: 'error', error }]`, `error.code` is `USER_CANCELED` |
| Another prompt outcome: a lockout, a failed scan | `skipped` with `reason: 'error'` and the prompt's code |
| No such item | `skipped` with `reason: 'notFound'` |
| The key is taken in this package | `skipped` with `reason: 'exists'`, nothing overwritten |

A canceled prompt is no exception: the user can try again, and the old item is still there for the next call. An item that isn't protected moves without a prompt, as with `migrateFrom…`.

```ts
import { KeychainErrorCode, isKeychainError } from '@apexnative/keychain/migrate';

const [skipped] = report.skipped;
if (skipped && isKeychainError(skipped.error, KeychainErrorCode.UserCanceled)) {
  showPasswordForm(); // and offer the move again next time
}
```
