## Usage {#usage}

```ts
import { isKeychainError, KeychainErrorCode } from '@apexnative/keychain';

try {
  await vault.getItem('refreshToken');
} catch (error) {
  if (isKeychainError(error, KeychainErrorCode.KeyInvalidated)) return signInAgain();
  if (isKeychainError(error)) log(error.code, error.nativeCode);
  throw error;
}
```

## Signature {#signature}

### Returns {#returns}

`true` when `error` is a [`KeychainError`](./KeychainError) and, if `code` is given, its code is that one. In TypeScript the error is a `KeychainError` from then on.

It is `error instanceof KeychainError`, with the code compared: one line instead of two in each `catch`. `@apexnative/keychain/migrate`, `/compat` and `/jest` export the same function, for the same class.
