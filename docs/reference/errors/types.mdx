## KeychainErrorDetails {#keychainerrordetails}

```ts
type KeychainErrorDetails = {
  nativeCode?: number;
  nativeDomain?: string;
  cause?: unknown;
};
```

The third argument of the [`KeychainError`](./KeychainError#constructor) constructor: what the native side said, kept for logs.
