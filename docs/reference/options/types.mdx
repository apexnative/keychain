## Prompt {#prompt}

```ts
type Prompt = {
  title?: string;
  subtitle?: string;
  description?: string;
  cancel?: string;
  fallback?: string;
  confirmationRequired?: boolean;
};
```

The texts of the system prompt that a read of a protected item shows: the `prompt` of [`createKeychain`](/api/options/KeychainOptions#prompt) and of a read's [`GetOptions`](/api/storage/types#getoptions). A read's prompt is merged over the storage's field by field. A field a platform doesn't have is ignored there, so one prompt works for both; a field that isn't given leaves the system's text.

<Params
  label="Field"
  items={[
    { name: 'title', type: 'string', text: 'iOS: the reason shown with Face ID or Touch ID (`LAContext.localizedReason`). Android: the title of the prompt.' },
    { name: 'subtitle', type: 'string', text: 'Android only: the subtitle.' },
    { name: 'description', type: 'string', text: 'Android only: the description.' },
    { name: 'cancel', type: 'string', text: 'The cancel button. iOS: `localizedCancelTitle`. Android: the negative button, shown only for a value without the passcode; with the passcode the system shows its own button to enter it.' },
    { name: 'fallback', type: 'string', text: 'iOS only: the fallback button after a failed scan (`localizedFallbackTitle`); `\'\'` hides it. For an item of biometrics alone (`biometryAny`, `biometryCurrentSet`), a tap ends the read with `USER_FALLBACK`; for the others, the fallback is the passcode.' },
    { name: 'confirmationRequired', type: 'boolean', default: 'true', text: 'Android only: whether a face match needs a tap to confirm.' },
  ]}
/>

```ts
const vault = createKeychain({
  accessControl: AccessControl.BiometryCurrentSet,
  prompt: { title: 'Unlock your account', cancel: 'Use password', fallback: 'Use password' },
});

await vault.getItem('refreshToken', { prompt: { title: 'Confirm the payment' } }); // cancel stays
```

## AndroidOptions {#androidoptions}

```ts
type AndroidOptions = {
  keyStorage?: KeyStorage;
};
```

The options for Android only: the `android` option of [`createKeychain`](/api/options/KeychainOptions#android) and of a write's [`SetOptions`](/api/storage/types#setoptions). iOS ignores them.
