}

## Signature {#signature}

```ts
function isPasscodeSet(): Promise<boolean>;
```

<Facts returns="Promise<boolean>" prompt="Never" />

`true` when the device has a screen lock: a passcode on iOS, a PIN, a pattern or a password on Android (`KeyguardManager.isDeviceSecure`).

Every `accessControl` but `'none'` needs it, and so does `accessible: 'whenPasscodeSetThisDeviceOnly'`: without one, their writes fail with `PASSCODE_NOT_SET`. To ask about one protection, [`canUseAccessControl`](./canUseAccessControl) is more precise: it answers `passcodeNotSet` among its other reasons.
