What [`getHardwareSecurityLevel`](./getHardwareSecurityLevel) answers for the device, and what [`getItemInfo`](/api/storage/methods#getItemInfo) reports as `android.securityLevel` for an item.

## Usage {#usage}

```ts
import { HardwareSecurityLevel, keychain } from '@apexnative/keychain';

const info = await keychain.getItemInfo('accessToken');
const inHardware = info?.android?.securityLevel !== HardwareSecurityLevel.Software;
```

## Values {#values}

| Constant | String | The key lives in |
| --- | --- | --- |
| `Strongbox` | `'strongbox'` | A StrongBox secure element: a separate chip with its own processor and storage |
| `Tee` | `'tee'` | The Trusted Execution Environment of the main processor |
| `Software` | `'software'` | Software only: an emulator, or a device without secure hardware |

The same strings name the hardware in [`KeyStorage`](/api/options/KeyStorage), the option that asks for it.
